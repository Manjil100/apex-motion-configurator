# APEX MOTION

Configure your dream. Experience the difference.

An independent concept platform for configuring performance cars in 3D. Not affiliated with any vehicle manufacturer.

**Status: Phases 1, 2, 4 and 6 complete; Phase 3 waiting on an asset.** The configurator runs a real-time 3D studio and a customisation engine that switches off options a model cannot show. Customers can create accounts, save builds to them, and send enquiries; data is protected by Row Level Security in Supabase. No licensed car model exists yet, so catalogue cars show a labelled material sample, not a car.

## Run it

Requires Node 20.9 or newer (built and tested on Node 22).

```bash
npm install
npm run dev        # http://localhost:3000
```

Other scripts:

| Command | Does |
| --- | --- |
| `npm run build` | Production build |
| `npm start` | Serve the production build |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript, no emit |
| `npm test` | Unit tests (Vitest) |
| `npm run asset:inspect -- model.glb [--out draft.json]` | List a model's real parts, materials, textures, size and problems; optionally write a draft manifest |
| `npm run asset:optimise -- in.glb out.glb [--ratio 0.5] [--texture 2048]` | Shrink a model for the web: simplify, WebP textures, Meshopt compression, names kept |
| `npm run asset:fixture` | Rebuild the loader test model (blocks, not a vehicle) |

Copy `.env.example` to `.env.local` and fill in the Supabase URL and publishable key. Without them the site still runs, with accounts and the contact form switched off and saying so.

## Stack

Next.js 16 (App Router, Turbopack, Cache Components, `proxy.ts` for session refresh), React 19, TypeScript, Tailwind CSS 4, Zustand, Three.js with React Three Fiber and Drei, GSAP for camera moves, Supabase (Postgres, Auth, Row Level Security). Framer Motion is installed but not yet used.

## Rules the code follows

- **No fake 3D.** Until a car has a licensed, verified model, the interface shows the empty studio bay with the car's generation code. It never shows a stand-in car or a static picture presented as 3D.
- **No invented facts.** Values that could be read as manufacturer figures are wrapped in `Sourced<T>` with a status of `verified`, `unverified` or `illustrative`. Performance figures, dimensions and base prices are blank until verified. Option prices are illustrative and labelled.
- **No editorial-only assets without sign-off.** `VehicleAsset.licence.commercialUse` must be true before a model is marked verified; a unit test enforces it.

## Deploying

Vercel project `apex-motion-configurator`, linked to this repository; every push to `main` deploys to production. `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` are set in Vercel for all environments.

Supabase project `apex-motion` (Sydney). In the Supabase dashboard under Authentication, URL Configuration, the Site URL must be the live address and the redirect list must include `https://apex-motion-configurator.vercel.app/**` and `http://localhost:3000/**`, or the links in confirmation and reset emails will point to the wrong place.

To make someone an admin, run in the Supabase SQL editor: `update public.profiles set role = 'admin' where id = (select id from auth.users where email = 'you@example.com');`
